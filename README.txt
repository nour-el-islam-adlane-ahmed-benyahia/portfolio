Nour El Islam Adlane Ahmed Benyahia - Portfolio

Files
- index.html  : page structure
- style.css   : design (colors are the variables at the top)
- script.js   : English/French texts, projects (WORKS list), certificates (CERTS list), project windows
- img/        : project and certificate pictures
- cv/         : CV downloads (English and French PDFs)

Put it on GitHub Pages
1. Create a repository (for example: portfolio, or <username>.github.io).
2. Upload ALL the files and folders of this zip (index.html must be at the top level).
3. Settings > Pages > Source: "Deploy from a branch" > main > / (root) > Save.
4. Wait a minute. The site opens at https://<username>.github.io/<repository>/

To add a project or certificate: edit the WORKS or CERTS list in script.js and add a picture in img/.
